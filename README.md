# Internet Connection Checker 🌐
A lightweight JavaScript utility that detects real-time network status changes.

## 🛠️ Features
* **Live Detection**: Instantly detects when the user goes online or offline.
* **Dynamic UI**: Updates status indicators in real-time using Event Listeners.
* **User Feedback**: Clear visual alerts for connectivity status.
